# Que Berraco Café

## Objetivo

Crear un sitio web moderno y responsive para presentar
la marca Que Berraco Café, sus productos, servicios,
experiencias y canales de contacto.

## Público objetivo

- Clientes particulares
- Empresas
- Turistas
- Negocios relacionados con café
- Personas interesadas en experiencias cafeteras

## MVP

- Página de inicio
- Información de la empresa
- Productos
- Servicios
- Experiencias
- Galería
- Contacto
- Enlaces a redes sociales

## Tecnologías

Frontend:
- React
- Vite
- JavaScript
- HTML
- CSS

Backend futuro:
- Node.js
- Express
